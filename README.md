# English30 · 英文训练台

面向 iPad 和电脑的 HKDSE 英文练习网站，围绕原卷精听、逐词字幕、题目原音证据、阅读和写句练习。

**[打开公开网站](https://english30-listening.philipwwq.workers.dev/#listening)** · 无需登录

## 听力练习

「听力练习」默认进入 **原卷精练**，可直接选择年份、正式／Practice／Sample、Part 和 Task。所有可播放 Task 接入同一套首答、逐词复盘、证据回听和无提示复测界面；「选段与导入」保留短篇与自导材料入口。原卷库仍可浏览其他 Paper 的题卷、Data File、原稿和评分参考。

- 覆盖 2012–2025 年及 Practice 的 15 套完整可播放录音、150 个 Task 入口。
- 129 份原件、4,675 页；按原始文件身份保留来源，并区分题卷、原稿和评分材料。
- 逐词字幕、点词重听、原句／Task 循环、范围证据播放、跨音频分段拖动，以及复习标记跟随。
- 低置信词只提供整句定位；没有可靠证据片段的题号明确标为待核实。
- 2012 Sample 原卷与原稿可浏览，但提供的录音不匹配，因此不提供虚构字幕或错误录音。

150 个 Task 精练包共用 75 份原音分段。Part A 按 Task 保留完整句子；Part B 的不同 Task 共用原对话，配合 Data File 和长答输入。首答与复测仅显示安全题页，提交后才开放逐词字幕、题目证据和评分参考。已核实规则的 21 道题保留自动参考表达比对；其余题直接作答后自核，待自核结果不会计为错误或虚构官方分数。

原卷内已提供 **「短句听写 · 先听再对照」**：在 Part A／B1 选择可靠短句，只听这一句并输入听到的内容，提交后对照原句，再记录自己的卡点。可区分「认识但听不出」、词义、词尾／数字、拼写及整句意思等问题；若原稿可能有误，可标为待核实，不计入正确率。

精练题卡的「练这一处」可直接进入对应证据短句，完成后返回原题；2025 Part B1 Task 6 可直接进入已整理的综合练习。阅读选证据保留当前题目，B1 自核逐项进行；写句已合理时可直接换情境，跟打为可选练习。

点击「关提示，再测一次」会隐藏字幕与反馈、清空本轮输入并恢复原速。首答、辅助练习和复测分别记录；已经看过提示、重复听或变速的练习不会冒充独立首答。字词差异只帮助定位漏听和拼写问题，不代表整句理解或 DSE 得分。设计依据与限制见 [学习设计评估](LEARNING-DESIGN.md)。

练习以 A+B1 为重点。B2 材料保留作参考。阅读、写句、原音听写、B1 综合练习及备份功能也可使用。训练计划是最后一个可选入口，不自动安排。

## 学习纪录

原卷复习标记、已提交的短句听写和卡点先暂存；点击「保存本次学习纪录」并确认摘要后，才写入当前浏览器并回读验证。已保存的标记可在刷新后恢复，从复习入口返回原音或进行关提示复测。未提交的输入不包含在正式保存中。

所有页面共享保存状态和「复习与备份」入口；听力、阅读、B1、写句与短句听写用一次摘要确认保存。保存期间的新修改仍会提示未保存。复习优先关提示作答，手动自评与实际练习记录分开；练习次数和同题改善不等于 DSE 等级或新题表现。

数据只在当前设备的当前浏览器中，没有云端账号、自动同步或后台收集。「待复习与备份」的完整备份已包含原卷标记、短句听写及其他模块已保存的记录；可导入其他设备或网址，校验后合并现有记录。备份不包含大型音频与试卷图片。清除网站数据前应自行备份。

题库的自动比对与声学时间轴不等于逐字人工听校。系统不会把自由表达自动换算为官方 DSE 分数。iPad 尺寸和触摸交互已用浏览器模拟检查，实体 iPad Safari 尚未完整实机验收。

## 本地运行

需要 Node.js 22 或更新版本。网页使用原生 HTML、CSS 和 JavaScript，无前端框架运行时。

```sh
npm ci
npm run assets:download
npm start
```

打开 <http://127.0.0.1:4173>。

Git 仓库包含源码、字幕、题目数据和媒体清单，音频与试卷图片不放进 Git 历史。`assets:download` 从上述公开站点恢复约 **1.4 GB / 4,915 个媒体文件**，逐个校验大小与 SHA-256。中断后重新运行会复用已完整校验的文件，未完成的文件重新下载；不会从任意来源执行代码。站点若停止提供原文件，恢复会明确失败，不会把错误内容当成功。

媒体恢复完成后，网站和全库测试可使用本地文件。没有自动离线缓存或仅凭 MP3 自动生成字幕的服务。

安装 FFmpeg／FFprobe 后，可用 `npm run papers:build` 从已整理的原卷时间轴和音频块重建 Task 分段。生成的范围、时长、哈希及字幕来源可在 `web/papers/practice-audio.json` 和各练习包中核对。

## 检查

```sh
npm run check
npm test
```

首次运行浏览器检查时安装 Playwright 和 Chromium，然后保持 `npm start` 运行：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:pastpaper
npm run test:papers
npm run test:study
npm run test:player
npm run test:platform
npm run test:journey
```

可用 `TEST_URL` 检查另一个部署网址，用 `PLAYWRIGHT_PACKAGE` 和 `CHROMIUM_EXECUTABLE` 指定已有浏览器环境。浏览器测试使用独立上下文，不应指向含真实学习纪录的个人浏览器配置。测试产物放在 `tests/artifacts/`，不进入 Git。

## Cloudflare 发布

先恢复媒体并通过本地检查，再使用自己的 Cloudflare 账号：

```sh
npx --yes wrangler@4.129.0 login
npm run check:cloudflare
npm run deploy:cloudflare
```

`wrangler.jsonc` 不包含账号 ID、密钥或数据库绑定。发布到自己的账号前可改 Worker 名称。静态资源与小型 Worker 分开上传；后续只传内容变更的资源。音频由 Worker 补充真实 HTTP Range／HEAD 支持，以兼容 Safari 的媒体探测与拖动。
